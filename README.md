# scopico-web-presentation

A static website served directly from the root `index.html` file. No dependencies
or build step are required.

## Publish with GitHub Pages

1. Merge the homepage changes into the repository's default branch.
2. Open [Settings → Pages](https://github.com/scopico-admin/scopico-web-presentation/settings/pages).
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the default branch and **/ (root)**, then click **Save**.
5. Wait for the Pages deployment to finish. The published site will be available at
   <https://scopico-admin.github.io/scopico-web-presentation/>.

These settings require repository admin access and are not enabled by adding
`index.html` alone. If Pages is unavailable, check your permissions and plan:
public repositories support Pages on GitHub Free; private repositories require
a plan that supports Pages. Organization policies may also restrict publishing.

## Preview locally

Open `index.html` in your browser. Edit that file to update the homepage.
